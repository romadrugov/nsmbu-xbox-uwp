# Xbox 0.6.0: безопасная проверка RPX перед запуском игры

Цель: читать и проверять **структуру** реального `red-pro2.rpx` на Xbox,
не пытаясь выполнить в UWP PowerPC-инструкции и не публикуя Nintendo-файлы.

## Что делает версия

1. Встроенный в сборку **публичный синтетический** RPX создаётся
   `recomp/android_fixture.py` и содержит 3 инструкции PPC, возвращающие 42.
   `xbox/smoke/make_public_rpx_header.py` упаковывает только эти открытые
   тестовые байты в заголовок, генерируемый при CI.
2. Независимый ограниченный парсер `runtime/src/core/rpx_inspect.*`
   проверяет ELF32 Big Endian, PowerPC, тип executable, таблицу секций,
   строки имён, диапазоны файловых данных, адреса, секции с
   `SHF_RPL_ZLIB` и точку входа. Парсер **не распаковывает** zlib.
3. На Xbox синтетическая `.text` копируется в ранее зарезервированное
   гостевое адресное пространство (только 12 байт, в одном 64-КиБ коммите).
   Это тест гостевого размещения данных, **не попытка исполнения PPC из памяти**.
4. Приложение необязательно открывает пользовательский файл
   `LocalState/red-pro2.rpx` и проверяет его структуру, затем считает
   SHA-256 через Windows BCrypt. Хеш сопоставляется со списком сборок,
   который автоматически генерируется из `recomp/builds.py` при CI.
   Неизвестный хеш распознаётся как неизвестная версия, а не исполняется.
   Парсер ограничивает размер файла 96 МиБ и проверяет диапазоны.
5. В этой версии **никакие реальные секции Nintendo не копируются**
   в гостевую память, не декомпрессируются и не исполняются.

## Проверка на Xbox Series S

Установи из GitHub Actions AppX `NSMBUXboxSmoke_0.6.0.0_x64.appx`.

Без дополнительных файлов ожидаются строки:

```text
NSMBU Xbox RPX Inspection Probe v0.6.0 started
[rpx/0.6] PUBLIC: entry=02000000 ...
[rpx/0.6] PUBLIC .text mapped into sparse guest memory PASSED
[rpx/0.6] LOCAL red-pro2.rpx not provided; PUBLIC fixture test only
```

Если хочешь также проверить **свою копию RPX**, открой Xbox Device
Portal → File explorer → User Folders → LocalAppData → пакет
`Romadrugov.NSMBUXboxSmoke` → `LocalState` и добавь туда
`red-pro2.rpx`. Не добавляй его в GitHub, GitHub Issues, Actions или
публичные артефакты. При замене/переустановке пакета LocalState может
сброситься — оригинал держи локально.

Ожидается `[rpx/0.6] LOCAL image read`, информация о секциях,
`LOCAL SHA256 recognized: <build>` либо
`LOCAL SHA256 NOT recognized ...`, и
`LOCAL inspection finished; execution DISABLED`.
Тестовая D3D12-шахматная текстура и кнопка A останутся рабочими.

## Что пока отсутствует

- Фактический локальный загрузчик game content и распаковка zlib секций.
- Сопоставление региональных вариантов с рекомпилированными таблицами.
- Релокации RPX/RPL, системные импорты OS, планировщик потоков.
- Выполнение рекомпилированных игровых функций, шейдеры и игровое меню.

Сборка 0.5.0, проверенная на физической Xbox, сохранена в
`xbox-uwp-stable-0.5.0`. Следующая стадия — предварительное
размещение секций в гостевой памяти с проверкой контрольных сумм,
а потом уже отдельная попытка запуска после подключения необходимых HLE.
